# Graylog Message Trace Wiki

Explains the path of a Graylog message while keeping three things apart: stored facts, recorded execution and replay results.

**Status:** development foundation, not an installable Graylog plugin. A read-only Node.js CLI can retrieve one authorised stored
message through Graylog's REST API. Native plugin, exact recording, processing reconstruction and replay are not implemented (README).
